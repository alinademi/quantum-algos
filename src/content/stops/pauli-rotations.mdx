<Depth level="kid">

Imagine several arrows whose combined pattern controls a turn. First adjust their coordinate lines so they can all be compared in the same direction. Next use reversible instructions to collect whether an odd or even number of marks are on into one place. Make a turn whose effect depends on that combined answer. Then undo the collecting and the coordinate changes. Only the desired combined effect remains, and the original work space is restored. You cannot generally reproduce this action by turning each arrow separately. The picture breaks because those marks describe components of a quantum state, not definite switches, and the turn changes complex wave amplitudes.

</Depth>

<Depth level="student">

To build a rotation generated by a [Pauli string](/learn/pauli-strings/) such as XYZ, map each active letter into Z: H on X sites, S† then H on Y sites, and nothing for Z or I. Use [CNOTs](/learn/cnot/) into one active wire to collect the parity of all active sites. Apply RZ by twice the exponent angle, 2θ, then undo the CNOTs and basis changes. The resulting [matrix exponential](/learn/matrix-functions/) acts on all three wires together, not as three independent [rotations](/learn/rotations/). For the all-identity string the result is only a global phase, so no gate is needed if it acts alone. With k active letters and k at least 1, this construction uses 2(k−1) CNOTs and one RZ, plus the local changes. Try a string with an identity site to see that it is skipped.

</Depth>

<Depth level="engineer">

Since $P^2=I$, $e^{-i\theta P}=\cos\theta I-i\sin\theta P$. If B maps P to a product of Z operators, compute their parity onto a chosen target with a CNOT network C. Then $B^\dagger C^\dagger R_Z(2\theta)CB=e^{-i\theta P}$. The factor of two comes from the definition of RZ. A string with $k\ge1$ active sites uses $2(k-1)$ CNOTs in this construction. If $P=I$, the exponential is $e^{-i\theta}I$, just a global phase for an unconditional operation; a controlled version must account for that phase.

</Depth>
