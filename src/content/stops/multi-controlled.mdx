<Depth level="kid">

A lock can require several keys. Only when every key is present does the target flip. Temporary helper wires can hold intermediate answers.

</Depth>

<Depth level="student">

Compute the AND of the first controls into clean scratch wires, flip the target using the last control, then undo the scratch calculation. With three controls this needs one clean scratch and three Toffoli gates.

</Depth>

<Depth level="engineer">

For $k$ positive controls, $C^kX|a_1\ldots a_k,t\rangle=|a_1\ldots a_k,t\oplus\prod_j a_j\rangle$. The displayed clean-ancilla ladder for $k\ge2$ uses $k-2$ ancillas and $2k-3$ Toffoli gates. This is one resource tradeoff, not an optimality statement; ancillas must start and finish in 0. With no scratch, conjugate a multi-controlled Z by H on the target. For m active wires, expand $2^{m-1}\prod_j b_j$ as an alternating sum of XORs over all nonempty subsets: the sign is positive for odd-size subsets, negative for even. Compute each parity onto an existing wire, apply a phase of $\pm\pi/2^{m-1}$, then undo the parity. This exact construction uses no ancillas but has exponentially many phase terms.

</Depth>
