<Depth level="kid">
Three coins can land in 8 patterns, from heads-heads-heads to tails-tails-tails. Add a fourth coin and there are 16. Each new coin doubles the count.

Qubits have patterns too: 000, 001, 010 and so on, up to 111 for three qubits. To describe three qubits, you need 8 numbers called amplitudes, one for each pattern. Measure the qubits and you get just one pattern. The amplitudes set the odds.

People must also agree which qubit is written first. Think of a date: in some countries 3/4 means March 4, in others April 3. This site writes qubit 0 on the left. Qiskit, a kit for programming quantum computers, writes it on the right.

The coins are only a picture. Three coins are always in one of the 8 patterns. Three qubits are not secretly in one pattern: their amplitudes can add up or cancel, which plain odds never do.
</Depth>

<Depth level="student">
One qubit needs 2 amplitudes, for 0 and for 1. Two qubits need 4, for 00, 01, 10 and 11. Each new qubit doubles the count: n qubits need 2ⁿ amplitudes. Thirty qubits need over a billion.

Measuring every qubit gives one string, with chance |amplitude|². The chances add up to 1. Example: two qubits, each started as 0, then a Hadamard gate. All four amplitudes are 1/2, so each string has a 1 in 4 chance.

Two rules fix the order. First, list the strings in counting order. A string read as a binary (base 2) number is then its place in the list, counting from 0: 10 is entry 2. Second, agree which qubit is which digit. This site, like Nielsen and Chuang, writes the first qubit on the left; Qiskit writes it on the right. IBM's course in Learn more uses Qiskit's order. So "qubit 0 is 1, qubit 1 is 0" is 10 here, but 01 in Qiskit.
</Depth>

<Depth level="engineer">
An $n$-qubit state is a unit vector with $2^n$ complex entries, one per bit string:

$$
|\psi\rangle = \sum_{x \in \{0,1\}^n} \alpha_x |x\rangle
$$

with $\sum_x |\alpha_x|^2 = 1$. Measuring every qubit gives the string $x$ with probability $|\alpha_x|^2$.

**Basis order.** The strings are listed alphabetically. So $|x\rangle$, with $x = x_0 x_1 \cdots x_{n-1}$ read left to right, is entry $\sum_{j=0}^{n-1} x_j\, 2^{\,n-1-j}$: the string read as a binary number.

**Qubit order** is a separate choice. Big-endian writes $|q_0 q_1 \cdots q_{n-1}\rangle$, so qubit $k$ has weight $2^{n-1-k}$; this site, like Nielsen and Chuang, writes the first qubit on the left. Little-endian (Qiskit) writes $|q_{n-1} \cdots q_1 q_0\rangle$, so qubit $k$ has weight $2^k$. One physical state gives two vectors that differ by reversing the bits of every index. Take $n = 3$ with qubit 0 in $|1\rangle$ and the rest in $|0\rangle$. Big-endian gives $|100\rangle$, entry 4. Little-endian gives $|001\rangle$, entry 1. The choice also fixes matrices: a gate $U$ on qubit $k$ is $I \otimes \cdots \otimes U \otimes \cdots \otimes I$, with $U$ in slot $k$ from the left (big-endian) or from the right (little-endian).

**Product states.** Qubits prepared each on its own give a tensor product, and amplitudes multiply. In big-endian order, $|\phi_0\rangle \otimes \cdots \otimes |\phi_{n-1}\rangle$ has

$$
\alpha_x = \prod_{k=0}^{n-1} \langle x_k | \phi_k \rangle.
$$

That takes only $2n$ amplitudes, 2 per qubit, fewer than $2^n$ once $n \ge 3$. A general state needs all $2^n$; the states that do not factor are [entangled](/learn/entanglement/).
</Depth>
