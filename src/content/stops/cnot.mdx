<Depth level="kid">

Imagine two switches. The first tells a machine whether to flip the second. If the first is off, nothing changes. If the first is on, the second flips. The first switch itself is not read or changed by the classical rule. Running it twice returns both switches.

Here is where the picture breaks: a quantum switch can have amplitudes for more than one possible result. Started with an even wave for the first and the second in 0, the machine links the pair. When measured in the 0/1 test they always agree, but either pair can come out. They are linked as one quantum state, not two hidden switches.

</Depth>

<Depth level="student">

CNOT is a two-qubit gate with an ordered control and target. For input 00 or 01 it does nothing; 10 becomes 11 and 11 becomes 10. The control is not measured. Apply the same gate twice and it undoes itself.

Prepare the control in |+⟩ and the target in |0⟩. CNOT gives a Bell state, (|00⟩ + |11⟩)/√2, which is [entangled](/learn/entanglement/). Its equal amplitudes for 00 and 11 give either result with equal chance. The two qubits no longer have separate pure states. If the target instead starts in |+⟩, nothing changes: entanglement depends on the input, not merely the gate.

</Depth>

<Depth level="engineer">

For basis states $|a,b\rangle$, CNOT maps $|a,b\rangle\mapsto|a,a\oplus b\rangle$. It is a unitary permutation and $CX^2=I$. Reversing control and target changes the matrix.

By linearity, starting with $|+\rangle|0\rangle$ gives $(|00\rangle+|11\rangle)/\sqrt2$, an entangled Bell state: each reduced state is $I/2$. In contrast $|+\rangle|+\rangle$ is unchanged since X has eigenvalue +1 on the target. A [multi-qubit state](/learn/multi-qubit/) cannot in general be expressed as a product. The [Pauli X gate](/learn/pauli/) is applied coherently in the control-one branch. The gate does not copy arbitrary unknown qubits.

</Depth>
