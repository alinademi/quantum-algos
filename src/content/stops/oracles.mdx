<Depth level="kid">

A secret box answers a question without showing how it works. In a quantum algorithm the box must also work when the question is in superposition.

</Depth>

<Depth level="student">

A bit oracle adds a Boolean answer into a target using XOR. With target 0 the result is the function value. With target |−⟩ the target stays the same and the input receives a phase of −1 wherever the function is 1.

</Depth>

<Depth level="engineer">

The bit oracle is $U_f|x,y\rangle=|x,y\oplus f(x)\rangle$, hence $U_f^2=I$. A phase oracle is $O_f|x\rangle=(-1)^{f(x)}|x\rangle$. Since X has eigenvalue −1 on |−⟩, $U_f(|x\rangle|{-}\rangle)=(O_f|x\rangle)|{-}\rangle$. Oracle query counts treat the oracle as a primitive; actual construction can be expensive.

</Depth>
