<Depth level="kid">

Imagine asking a secret box many questions, each with its own amplitude, in one wave. The box changes the wave so that each question is linked to its answer. You cannot pull out a list containing all the answers. Reading the wave once gives you only one question and its answer. Ask again with a freshly prepared wave and you may get a different pair.

What makes this useful is that waves can be brought together afterward so their contributions reinforce or cancel. The picture breaks here: a quantum box does not answer many separate classical callers. It acts on one shared quantum state.

</Depth>

<Depth level="student">

Prepare two input qubits with equal amplitudes for the four bit strings and a target in |0⟩. A single [oracle](/learn/oracles/) call links each input to the function value, preserving the four amplitudes. A standard-basis measurement gives one input-output pair selected at random, each with chance 1/4. A fresh preparation is needed for each shot.

The truth table in this tool is supplied by the simulator for comparison, not read out of the quantum state. Changing the initial [multi-qubit state](/learn/multi-qubit/) changes the odds. An algorithm needs additional gates that make the contributions interfere in a useful way; merely querying a superposition is not a speedup.

</Depth>

<Depth level="engineer">

For a uniform input on n qubits, $U_f 2^{-n/2}\sum_x|x,0\rangle=2^{-n/2}\sum_x|x,f(x)\rangle$. Measuring in the computational basis yields each pair with probability $2^{-n}$. The [Holevo bound](/learn/holevo-bound/) limits the accessible classical information encoded in an ensemble of n-qubit states to at most n bits without a shared entanglement resource, not one bit per basis amplitude.

In [Deutsch's algorithm](/learn/deutsch/), use a one-bit input in |+⟩ and a target in |−⟩. [Phase kickback](/learn/phase-kickback/) makes the input proportional to $(-1)^{f(0)}|0\rangle+(-1)^{f(1)}|1\rangle$. H followed by measurement returns $f(0)\oplus f(1)$ exactly from one ideal query. The result is a property of the function, not a list of outputs. This is how interference leverages quantum parallelism.

</Depth>
