<Depth level="kid">

Imagine a toolkit that changes a fixed set of direction markings without inventing any new kinds of mark. One tool exchanges two directions; another sends one direction to a different direction with a possible sign change. A tool connecting two pieces can spread a mark across them. By combining these tools you still get only markings of the same kind, even when the pieces become linked. A different tool turns a marking partway between two directions, which breaks that rule. The picture breaks because these marks represent mathematical operations, not just arrows. The limited toolkit is important because its behavior can be tracked efficiently even for linked qubits.

</Depth>

<Depth level="student">

[Clifford gates](/learn/gottesman-knill/) map [Pauli strings](/learn/pauli-strings/) to signed Pauli strings when conjugating them. [H](/learn/hadamard/) exchanges X and Z and sends Y to −Y. S sends X to Y and Y to −X. [CNOT](/learn/cnot/) spreads X on the control to XX and Z on the target to ZZ. H, S and CNOT generate all Clifford operations up to global phase. T is outside this set: it sends X halfway between X and Y rather than to one signed Pauli. Although Clifford circuits can entangle qubits into Bell states, the signed-Pauli rule makes an important class of circuits efficient to simulate.

</Depth>

<Depth level="engineer">

The Clifford group is the normalizer of the n-qubit Pauli group: $UPU^\dagger$ is Pauli for every Pauli P. H, S and CNOT generate it up to global phase. For example $TXT^\dagger=(X+Y)/\sqrt2$ is not a Pauli. This conjugation closure enables tracking stabilizers without an exponential state vector, but Clifford gates can still create entanglement.

The ideas used here build on [Phase gates](/learn/phase-gates/), [Pauli gates](/learn/pauli/).

</Depth>
