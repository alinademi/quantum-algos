<Depth level="kid">

A detailed list of every possible quantum basis state gets huge as you add wires. Sometimes a pattern in the list lets you describe it much more simply.

</Depth>

<Depth level="student">

For a dense state vector on n qubits, store 2ⁿ complex amplitudes. At 16 bytes per amplitude this needs 16 × 2ⁿ bytes, before overhead. Product states, certain tensor networks and stabilizer states can have compact descriptions. A GHZ state has only two nonzero amplitudes.

</Depth>

<Depth level="engineer">

A generic pure-state vector requires exponentially many parameters; a dense density matrix has $4^n$ complex entries. Stabilizer tableaux use polynomial space, and tensor networks can exploit bounded bond dimension or favorable circuit structure. These are representation-dependent bounds, not a universal limit on exact or approximate simulation of a particular circuit. A state-vector simulator and a sampling algorithm need not store the same representation.

</Depth>
