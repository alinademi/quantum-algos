Write an answer on scratch paper, transfer the useful part to the result register, then run the scratch instructions backward. Keep the answer and clear the workspace.

<Depth level="student">

Toffoli computes AND into q2. CNOT from q2 into a fresh q3 stores the result. The inverse Toffoli returns q2 to 0. If the inputs were superposed, the desired result can remain entangled with them.

</Depth>

<Depth level="engineer">

For a reversible compute $U_f:|x,0\rangle\mapsto|x,f(x)\rangle$, compute, XOR the Boolean basis label into a fresh output, then $U_f^\dagger$ implements $|x,0,0\rangle\mapsto|x,0,f(x)\rangle$. The XOR does not clone arbitrary unknown states. This technique prevents needless garbage entanglement, provided the intervening operation leaves the information needed by the inverse intact.

</Depth>
