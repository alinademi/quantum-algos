<Depth level="kid">

Think of instructions for a machine. Each wire carries a qubit. Follow the instructions in order; the same instructions in a different order can give a different answer.

</Depth>

<Depth level="student">

A circuit starts with a state and updates it gate by gate. Gates on different wires can often run in parallel. H on the first wire followed by CNOT can make an entangled pair; the reverse order on 00 does not.

</Depth>

<Depth level="engineer">

With column vectors, chronological gates $U_1,\ldots,U_m$ give $U_m\cdots U_1|\psi\rangle$. Operations on disjoint subsystems commute, but overlapping ones need not. The lab uses the convention $|q_0q_1\rangle$, with q0 the most significant displayed bit. Measurement and classical control require more than a single unitary matrix.

</Depth>
