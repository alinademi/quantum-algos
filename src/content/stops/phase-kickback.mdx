<Depth level="kid">

A switch controls a wave that already has a special shape. The wave keeps its shape, but the switch branches now have different phases. A later H can reveal that phase.

</Depth>

<Depth level="student">

Prepare the control in |+⟩ and the target in |−⟩. X acts on |−⟩ by multiplying it by −1. Consequently CNOT changes the control to |−⟩ while leaving the target in |−⟩. Try a non-eigenstate to see how this can fail.

</Depth>

<Depth level="engineer">

If $U|u\rangle=e^{i\phi}|u\rangle$, then $C(U)(a|0\rangle+b|1\rangle)|u\rangle=(a|0\rangle+be^{i\phi}|1\rangle)|u\rangle$. H on a control initially in |+⟩ gives $p(1)=\sin^2(\phi/2)$. If the target is not an eigenstate, the control may become entangled with it. This is the mechanism used in phase estimation.

</Depth>
