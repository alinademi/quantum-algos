<Depth level="kid">

Imagine two labeled boxes and a lever. When the lever is off, leave the boxes exactly where they are. When it is on, exchange them. If one box carries a red ball and the other a blue ball, they trade places, but no ball is added or lost. Use the same lever and exchange again to undo it.

In a quantum experiment the lever has its own amplitudes. The two boxes may become linked to it through the exchange. The picture breaks because the boxes and lever do not have definite hidden values for every measurement; the exchange changes a joint quantum state.

</Depth>

<Depth level="student">

Fredkin is controlled SWAP. On input (c,a,b), control 0 leaves both targets alone; control 1 exchanges a and b. It never changes how many 1s there are: 101 becomes 110, for example. The gate is reversible.

One construction uses CNOT from a to b, [Toffoli](/learn/toffoli/) from c and b to a, then CNOT from a to b again. A superposed control |+⟩ with target bits 01 produces equal amplitudes for 001 and 110, an entangled state. The direct and decomposed versions have the same amplitudes for all inputs. Try a target pair with unequal bits to see the change.

</Depth>

<Depth level="engineer">

The controlled-SWAP matrix is $|0\rangle\langle0|\otimes I_4+|1\rangle\langle1|\otimes\mathrm{SWAP}$, so its square is identity. It also preserves the Hamming weight of every basis string, since it only permutes targets. Label control c and targets a,b. CNOT a→b, Toffoli (c,b)→a, CNOT a→b implements Fredkin; checking basis inputs proves the linear maps coincide.

</Depth>
