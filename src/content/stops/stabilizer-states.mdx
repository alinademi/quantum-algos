<Depth level="kid">

Imagine a puzzle with a huge list of possible patterns, but a few rules specify exactly one answer. Instead of writing the whole list, you write just the rules. Some quantum states can be described this way too. The rules are tests whose answers are certain even though other questions about the state have unpredictable answers. A state of three linked quantum pieces needs just three such independent rules instead of eight wave amplitudes. The picture breaks because these rules are mathematical operations acting on the state, not ordinary clues about hidden values. They can describe linked states that cannot be described piece by piece.

</Depth>

<Depth level="student">

A pure stabilizer state is specified by n independent commuting signed [Pauli strings](/learn/pauli-strings/) with eigenvalue +1. For |0⟩ the rule is +Z; for |+⟩ it is +X; for |1⟩ it is −Z. A Bell pair has rules XX and ZZ, so stabilizer states need not be product states. As [Clifford gates](/learn/clifford-group/) act, conjugate each rule to get the new rules. Since we only need n generators, three qubits need three rules rather than eight amplitudes, and 50 need 50 rather than 2⁵⁰. See [eigenvectors](/learn/eigen/) and [stabilizers](/learn/stabilizers/) for the links between these rules and certainty. Not every quantum state has this representation.

</Depth>

<Depth level="engineer">

A stabilizer group S is an abelian Pauli subgroup not containing −I. With n independent generators it has size $2^n$ and defines a one-dimensional common +1 eigenspace. $|\psi\rangle\langle\psi|=2^{-n}\sum_{g\in S}g$. If a Clifford U is applied, generators update as $g\mapsto UgU^\dagger$. The signs matter: −Z stabilizes |1⟩, whereas +Z does not. Store each generator using two binary coordinates per qubit for its X and Z factors, plus a sign. The n-generator description takes $O(n^2)$ bits rather than storing $2^n$ amplitudes. Independence means no nonempty product of generators is identity.

</Depth>
