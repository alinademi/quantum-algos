# Curriculum

Source of truth for The Map. Regions say what a stop is. Lines say the order to learn in. A stop can sit on many lines.

`Needs` lists stops you must learn first; `Deeper` lists optional stops that help you go further; a need on another line is a transfer. Open now: `superposition`. Merged from `docs/research/` (4 researchers); see those files for left-out topics.
